═══════════════════════════════════════════════════════════════════════════════
                        🔧 CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════

Refresh Rate: 10 seconds (configurable)
  - Change TTL in get_alpaca_account_data() function
  - Lower = more real-time, higher = fewer API calls

Credentials Required (.env file):
  Option 1:
    ALPACA_API_KEY=your_key_here
    ALPACA_SECRET_KEY=your_secret_here
  
  Option 2:
    APCA_API_KEY_ID=your_key_here
    APCA_API_SECRET_KEY=your_secret_here

Styling Customization:
  - Edit custom CSS in st.markdown() section
  - Adjust font sizes, colors, effects
  - Modify gradient backgrounds
